# PEYKR V.1

PEYKR is a privacy-first trusted-device communication and safety application. Devices establish persistent trusted relationships through mutual approval; there are no user accounts, registrations, central user profiles, or account recovery.

## Repository structure

- `android/` — Native Android application, planned with Kotlin and Jetpack Compose.
- `ios/` — Native iOS application, planned with Swift and SwiftUI.
- `shared/` — Shared product and cross-platform design material. Platform-specific application implementations remain in their native directories.
- `docs/` — Product, architecture, security, and platform-limitation documentation.

This repository currently contains documentation and structure only. Application features and supporting dependencies have not yet been implemented.
